# حارس جودة الواجهة UI Quality Gate

حارس إلزامي في GitHub Actions قبل اختبارات المتصفح العامة. يفحص الهاتف والحاسوب على Chromium:

1. عنوان H1 واحد في المحتوى، وتسلسل العناوين دون تخطي مستوى.
2. عدم تكرار النص الحرفي للعناوين الظاهرة داخل المحتوى؛ اسم القسم في التنقل لا يُعد تكرارًا.
3. منع التمرير الأفقي غير المقصود.
4. فحص WCAG 2 A/AA و2.1 A/AA باستخدام axe-core.
5. التحقق في الرئيسية ومكتبة الخطط والمهام، وفي إنشاء الخطة وتفاصيلها.
6. صور فعلية للحالة المعبأة تُحفظ ضمن artifact اختبارات المتصفح.

الأمر: npm run test:ui-guard

ملاحظة: الحارس يكتشف أنماطًا محددة من العيوب ولا يغني عن المراجعة البصرية البشرية. مقارنة الصور المرجعية البكسلية تحتاج اعتماد لقطات مرجعية ثابتة لاحقًا؛ لا ندعي تفعيلها الآن.
