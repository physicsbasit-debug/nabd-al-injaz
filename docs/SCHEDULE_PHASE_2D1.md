# 2-D1: جداول المعلمين الأساسية

- قائمة أسماء المعلمين والحصص تحفظ محليًا، دون قاعدة بيانات أو أي اتصال خارجي.
- إدخال يدوي وحارس تعارض يمنع وجود حصتين للمعلم نفسه في اليوم والحصة نفسها.
- استيراد XLSX جدولي فقط بعناوين المعلم واليوم والحصة، ومادة اختيارية. تُعرض معاينة، ولا يُعتمد الملف تلقائيًا.
- أي صف غير صالح يمنع الاعتماد؛ والتعارض مع البيانات السابقة يمنع اعتماد الدفعة بالكامل.
- المتفرغون محسوبون **من المعلمين المسجلين فقط**، وليسوا ترشيحًا تلقائيًا للاحتياط.
- لا تشمل المرحلة معالجة القوالب المدرسية المعقدة أو التوزيع الآلي أو الغياب؛ تُفصل في مراحل لاحقة بعد اختبار ملفات فعلية.
- حدود رقم الحصة 1 إلى 12، والأيام الأحد إلى الخميس.
- القبول: اختبارات المتصفح للحاسوب والهاتف، حفظ بعد التحديث، استيراد/رفض تعارض، البناء، lint، واجهة RTL.
