# مرحلة 2-B1: مكتبة الخطط اليدوية ومؤشر مستقل لكل خطة

## المنفذ
- أنواع الخطط الستة وخطة مخصصة؛ تسمح المنظومة بأكثر من خطة من النوع نفسه.
- إنشاء وتعديل وأرشفة واستعادة الخطط؛ أرشفة الخطة لا تحذف بياناتها.
- إضافة وتعديل وحذف أنشطة الخطة، مع حالة لم يبدأ/قيد التنفيذ/مكتمل.
- تاريخ الإكمال الحقيقي، والتفريق بين إكمال النشاط وتوثيقه.
- نسبة مستقلة لكل خطة في الصفحة الرئيسية، وحالة واضحة عند عدم وجود أنشطة.
- عدد المتأخر وقيد التنفيذ محسوب من الأنشطة، مع اعتبار تاريخ اليوم غير متأخر.
- تخزين الخطط في مفتاح محلي مستقل عن مهام المرحلة الأولى، مع قراءة دفاعية للبيانات.
- تنبيه عند تعذر الحفظ المحلي، وتحذير من عدم وجود مزامنة أو نسخة احتياطية.
- اختبارات حسابات وأنشطة وأرشفة وإعادة تحميل ومتصفح للهاتف والحاسوب.

## غير المنفذ عمدًا
- استخراج الأنشطة من Excel/Word/PDF: مرحلة 2-B2 بعد تجربة عينات حقيقية. لا ادعاء بأن الاستيراد يعمل.
- رفع الشواهد: مرحلة 2-B3 بعد اختيار التخزين المحلي المناسب؛ لذلك المكتمل يظهر «ينتظر التوثيق».
- لا حذف نهائي للخطط نفسها في هذه المرحلة؛ الأرشفة والاستعادة بدلًا من ذلك.
- لا حساب أوزان مختلفة ولا مزامنة ولا Supabase.

## بوابة القبول
- اختبارات npm test وnpm run test:unit وnpm run lint وnpm run format:check وnpm run build.
- Playwright على الهاتف والحاسوب، مع صور مراجعة فعلية.
- لا دمج في main دون اعتماد المستخدم. هذه مرحلة مبنية على فرع مراجعة 2-A.
