# 2-C4 | قبول تكامل الخطط والشواهد

## النطاق
اختبارات قبول عملية على Chromium بحجم حاسوب 1366×768 وهاتف بمحاكاة iPhone 13، تُنفذ في GitHub Actions.

- رفض الاستعادة الملغاة مع حفظ الخطط والمهام دون تغيير.
- رفض تكرار معرّفات الخطط ورفض نوع خطة غير معتمد قبل تغيير البيانات.
- تحقق من بقاء بيانات الخطط بعد إعادة التحميل.
- تحقق من ظهور أدوات النسخ والتقرير، ووضوح تركيز لوحة المفاتيح، وعدم وجود تمرير أفقي.
- التقاط صورتين فعليتين لحالة أدوات النسخ على الحاسوب والهاتف.

## حدود القبول
هذه اختبارات متصفح Chromium ومحاكاة شاشة هاتف، وليست اختبار Safari أو Firefox أو أجهزة فعلية.
لا تتضمن هذه المرحلة Supabase أو نقل بيانات المستخدم إلى الخادم.
لا يتم الدمج في main إلا بعد مراجعة النتائج واعتماد المالك.
