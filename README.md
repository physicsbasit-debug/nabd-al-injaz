# نبض الإنجاز

منظومة مستقلة لإدارة أعمال المعلم الأول.

**الحالة:** نموذج محلي تشغيلي للخطط والمهام والشواهد والجداول. مرحلة 2-D3B تضيف سياسة الإنصاف ومسودة توزيع احتياط آلية محلية؛ الربط الخادمي والصلاحيات والإرسال الآلي لم تُنفذ.

## النطاق
- لوحة مهام يومية ونسب إنجاز محسوبة.
- الخطط ومتابعة الإنجاز والشواهد.
- جداول Excel للمعلمين، ومعرفة المتفرغ حسب اليوم والحصة.
- مسودة توزيع احتياط يدوي أو آلي مع منع التعارض ومراعاة الاستثناء والرصيد؛ اعتماد التكليف ورسائل واتساب يبقيان بيد المستخدم.
- مراجعة الاختبارات القصيرة ومطابقتها لوثيقة التقويم.
- النشرة التوجيهية وتقدم تنفيذ المناهج حسب المعلم والمادة والصف، دون إدخال لكل شعبة.
- الصف الثامن: العلوم 6 حصص أسبوعيًا؛ الصفان التاسع والعاشر: الفيزياء والكيمياء والأحياء حصتان أسبوعيًا لكل مادة.
- الإنماء المهني وحضور المعلمين.
- روابط رفع إنجازات المعلمين، ومراجعتها واعتمادها.
- تقارير مستمدة من السجلات الفعلية.

## المبادئ
واجهة RTL احترافية، خطوط عربية واضحة، أكورديون منظم، مؤشرات دائرية، بنية قليلة التعقيد، لا نسخ من مسار، ولا خدمات مدفوعة في البداية.

## المرحلة الحالية
2-D3B: إعداد استثناءات المعلمين والرصيد السابق وأولوية التوزيع عند التعادل، مع توزيع آلي محلي يترك الحصص بلا بديل مؤكد دون تكليف. اختبارات الواجهة تغطي قالبًا بحجم الجدول المدرسي المعتمد (9 معلمين، 45 صف يوم، 162 حصة). لم يُرفع ملف المدرسة الحقيقي إلى واجهة منشورة بعد.

يحتوي هذا المستودع الواحد على المصدر وسير عمل البناء والنشر إلى GitHub Pages. عند الدفع إلى `main`، يبني GitHub الموقع من `src/` وينشر مجلد `dist/` مباشرة؛ لا حاجة إلى مستودع نشر منفصل. رابط Pages هو `https://physicsbasit-debug.github.io/nabd-al-injaz/`. لا يُضمّن ملف Excel أو بيانات المدرسة في البناء. يقرأ التطبيق الملف في المتصفح ويحفظ الجدول محليًا على الجهاز الحالي، دون تخزين مركزي أو مزامنة بين الأجهزة.
